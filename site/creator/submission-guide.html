Submission Guide

This package includes the storefront, not a live upload backend. Before enabling paid creator submissions, use a server-side workflow that quarantines every upload.

  1. Accept only approved package formats.
  2. Reject path traversal, executable server-side code, symlinks, encrypted archives, and oversized packages.
  3. Virus/malware scan.
  4. Inspect network calls and third-party trackers.
  5. Review IP ownership and age/content metadata.
  6. Serve approved games from an isolated origin with a strict Content Security Policy.

Recommended metadata: title, creator, age band, controller support, browser requirements, homebrew target, languages, content descriptors, and regional availability.
